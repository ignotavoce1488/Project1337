# Полный тестовый запуск на Windows 11 без VPS

В одном Linux-контейнере работают настоящий Telegram-бот, API, Mini App,
обработчик очереди, FFmpeg и HTTPS-туннель Cloudflare. Аудио распознаёт Gemini;
конспекты создаёт только OpenRouter.
Исходники, Python, Node.js и FFmpeg на Windows устанавливать не нужно.

## Первый запуск

1. Установите и запустите [Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/)
   с WSL 2 и Linux containers. Перезагрузите Windows, если попросит установщик.
2. Распакуйте `Slovech-Windows.zip` в обычную папку. Не запускайте файлы из окна ZIP.
3. Дважды нажмите `START-WINDOWS.cmd`. При первом запуске вставьте токен **отдельного тестового бота**
   из @BotFather, Gemini API key и OpenRouter API key. Ввод скрыт; настройки сохранятся в `.env.local`.
4. Дождитесь сборки образа и открытия Telegram. Отправьте `/start`, затем аудио
   или голосовое сообщение. Нажмите «Открыть конспекты» или кнопку меню «Конспекты».

Следующие запуски — только `START-WINDOWS.cmd`. Интернет нужен для Telegram, AI и туннеля.
На первом запуске также скачиваются Docker-образы и зависимости.
Ключи в `.env.local` хранятся открытым текстом локально, но не попадают в образ или ZIP.
Не передавайте этот файл вместе с архивом другим людям.

Модель OpenRouter уже указана в `.env.local`; её можно заменить, если бесплатный endpoint недоступен.
После изменения ключей нажмите `STOP-WINDOWS.cmd`, затем `START-WINDOWS.cmd`.
Gemini должен быть доступен вашему аккаунту, региону и иметь достаточную квоту;
реальные обращения к AI могут тарифицироваться.

## Почему используется туннель

Telegram требует HTTPS-адрес для Mini App. `localhost` другого устройства не указывает
на ваш Windows-компьютер, поэтому контейнер автоматически получает временный публичный
адрес `https://….trycloudflare.com`. Домен и аккаунт Cloudflare не нужны.
Открывается только API/Mini App; доступ к записям по-прежнему требует подпись Telegram.
Авторизация не отключается, тестовые данные не подменяют реальную обработку.

После перезапуска контейнера адрес может измениться. Кнопка меню бота обновляется
автоматически. Для старых сообщений нажмите `/start` заново: старые кнопки могут вести
на предыдущий адрес. Ручная настройка URL в BotFather не нужна для кнопок этого бота.
Не используйте токен бота, который одновременно запущен на VPS: polling будет конфликтовать.
Если у токена настроен webhook, запуск останавливается, а webhook не изменяется.

Это бесплатный [Quick Tunnel для тестирования](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/),
без гарантии доступности. VPN, корпоративная сеть или блокировка Cloudflare могут мешать запуску.

## Остановка, данные и диагностика

- `STOP-WINDOWS.cmd` останавливает весь комплект и сохраняет данные.
- `LOGS-WINDOWS.cmd` показывает журналы; Ctrl+C закрывает просмотр.
- `http://localhost:8000/ready` показывает готовность API.
- `http://localhost:8000/app` открывает интерфейс, но без входа через Telegram не показывает
  личные записи. Для полноценного теста используйте кнопку Mini App в Telegram.
- База и аудио хранятся в отдельных volumes проекта `slovech-local`; VPS не используется.
- После выхода из Docker Desktop или сна компьютера бот и Mini App недоступны.
- Встроенный публичный Telegram Bot API ограничивает скачивание входящих файлов 20 МиБ.
  Для проверки начните с короткой записи. Отдельный local Bot API в этот комплект не входит.

Если занят порт 8000, измените только левую часть `127.0.0.1:8000:8000` в `compose.local.yaml`,
например на `127.0.0.1:18000:8000`. Mini App продолжит работать через туннель.

## Сборка и перенос готового образа

Архив исходников формируется командой `python -m scripts.build_windows_bundle`.
В текущем комплекте образ собирается автоматически при первом запуске. Чтобы заранее
подготовить готовый образ для обычного Windows x64 на машине с Docker:

```sh
docker buildx build --platform linux/amd64 --target local-test -t slovech-local:2 --load .
docker save -o slovech-local-image.tar slovech-local:2
```

Положите `slovech-local-image.tar` рядом с `START-WINDOWS.cmd` в распакованную папку.
На новом компьютере стартовый файл сам загрузит образ, вместо сборки. Для Windows ARM
соберите `linux/arm64`. Секреты всё равно вводятся отдельно на целевом компьютере.

Для пересборки после изменения исходников:

```sh
docker compose --env-file deploy/windows/local.env -p slovech-local -f compose.local.yaml build --pull app
docker compose --env-file deploy/windows/local.env -p slovech-local -f compose.local.yaml up -d --force-recreate --wait
```

Удаление volumes удаляет тестовые конспекты и аудио. Скрипт остановки этого не делает.
